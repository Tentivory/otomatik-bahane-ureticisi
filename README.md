# Otomatik Bahane Üreticisi

## Giriş

Bu proje, insanlık tarihinin en büyük sorunlarından biri olan "iş yapmama" eylemini bilimsel, akademik ve son derece ciddi bir seviyeye taşımak amacıyla geliştirilmiştir. Artık "yorgunum" demek yerine, kuantum mekaniği ve istatistiksel termodinamik prensiplerine dayalı gerekçeler sunabilirsiniz.

### Özellikler

- Tamamen çalışan (bir şekilde) Python kodu
- Türkçe bahane üretimi
- Abartılı ciddiyet
- Hiçbir şey yapmama konusunda uzmanlaşmış algoritma

## Kurulum

```bash
pip install -r requirements.txt  # aslında gerek yok ama olsun
python bahane.py
```

## Kullanım

Kodu çalıştırın ve hayatınızı kurtaracak bahaneyi bekleyin. Beklerken bir çay demleyin, demlenmezse bu da bir bahanedir.

## Lisans

Bu proje "Yapılmasın Diye Yapıldı" lisansı altındadır. Kullanırsanız sorumluluk size aittir. Kullanmazsanız da yine size aittir.
